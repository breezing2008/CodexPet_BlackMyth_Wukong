# v1.0.0 — 天命人 / The Destined One

首次公开发布已完成的天命人 Codex 桌宠。原版形象、动画、清单与图集保持不变。 / First public release of the completed Destined One Codex desktop pet. Original character artwork, animations, manifest and atlas remain unchanged.

- 九类动画、十六朝向与十个循环 GIF。 / Nine states, sixteen directions and ten looping GIF previews.
- 中英双语使用说明、安装提示词、设计依据与个人使用声明。 / Bilingual usage, installation prompt, source notes and personal-use notice.
- 带 SHA-256 检查、旧版本备份与临时目录安全测试的 Python 安装脚本。 / Python installer with SHA-256 verification, old-version backups and temporary-directory safety tests.
- 完整项目 ZIP、仅宠物素材 ZIP 及各自校验值。 / Full-project ZIP, pet-only ZIP and their checksums.

下载完整包后，先阅读 README 和 NOTICE，再运行 `python3 scripts/install.py --dry-run` 与 `python3 scripts/install.py`。设置 → Pets → Refresh 后选择宠物。 / After extracting the full package, read README and NOTICE, run the dry-run and installer commands, then refresh Settings → Pets and select the pet.

需要支持自定义 v2 格式的桌面版本；不承诺网页上传或所有平台/版本兼容。保留部分斜向视线细微、受阻反应克制的原版视觉限制。 / Requires a desktop build supporting custom v2 pets; web upload and every platform/build are not guaranteed. Original subtle diagonal gaze and restrained blocked-reaction limits remain.

仅限个人、非商业使用；非官方同人项目，无游戏模型或官方参考原图。详见 NOTICE。 / Personal, non-commercial use only. Unofficial fan work; no game models or original official reference images are included. See NOTICE.
